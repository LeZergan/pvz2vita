Plants vs Zombies 2 for PS Vita - Version 1.1 RC29
Build: 452-v1.1-rc29 | Game: 4.5.2 ROW (version 147)

UPDATE
Install pvz2-vita-latest.vpk over the previous version.
Keep your existing game data and userdata/ saves.

FIRST INSTALL
1. Copy your matching libPVZ2.so and game.obb into ux0:data/pvz2/.
2. Install pvz2-vita-latest.vpk using VitaShell and launch.
The older main.147.com.ea.game.pvz2_row.obb filename is also supported.
Do not put a second pvz2 folder inside the first one.
The game creates userdata/ automatically. Back it up to preserve progress.
Updates do not require copying or renaming game data again.

REQUIREMENTS
A homebrew-enabled Vita with kubridge.skprx enabled under *KERNEL
in ur0:tai/config.txt. Reboot after installing the plugin.
Install the shader compiler using ShaRKBR33D. Its file belongs at:
  ur0:data/libshacccg.suprx
  or ur0:data/external/libshacccg.suprx
System plugins and commercial game data are not included.

CONTROLS
Left stick / D-pad: pointer. Right stick: precise pointer.
Cross: press; hold to drag. Circle: back. Start: game menu / pause.
L/R: focus the standard seed tray and remember the last slot.
Cross selects and returns to the lawn; Circle cancels tray focus.
Use the pointer or touch for special layouts, shovel and plant food.
Hold L+R, then Down+Cross to open the controls guide.
Pause with Start before opening the guide during a level.
Touch takes over from buttons. The pointer stays visible until touch or a system dialog takes over.
Tap text fields to open the Vita keyboard; Cancel keeps the old value.

STARTUP SETTINGS / MODS
Hold D-pad Down + Cross + L + R during the first 1.5 seconds of boot.
Release all launch buttons when settings appear; input waits for release.
RC29 uses double buffering to address redraw flashing and resets RC26/RC27
language preferences once to override Off / automatic English. Later explicit
changes persist when saved with Done.
If the chord is difficult to time, create an empty file at:
  ux0:data/pvz2/userdata/port_menu.txt
Remove that file when finished; while it exists, every boot opens settings.
Settings show the selected OBB filename, location, size and RSB information.
Language override starts Off: automatic English, including mods translating
English assets. Turn it On to choose English, German, Spanish, French,
Italian or Brazilian Portuguese (when that archive contains those locales).
Select a player and edit coins/gems. Left/Right selects a digit; Up/Down changes
it; Cross accepts the staged value. No save is written until Done.
Circle during number entry cancels that value and returns to the settings rows.
Done applies pending changes and exits. Relaunch the game to use the settings.
All edited players commit in one backed-up save transaction. Existing balances
above 999999999 are preserved unless explicitly edited; entry uses nine digits.
If currencies save but settings fail, the screen reports it and lets you retry.
Circle exits and discards pending changes. Original saves are backed up as
userdata/No_Backup/pp.dat.backup-N; restore with the game closed if needed.
Missing or unsupported/encrypted saves remain untouched; language settings work.
OBB size/hash checks and the stock bundled resource index are removed.
Use game.obb compatible with the 4.5.2 engine; native library must still match.
If both archive filenames exist, game.obb takes priority. Close the game before
replacing a mod archive and back up userdata/ before switching mods.
The installed archive is indexed on boot, so mod support can add startup time.
All optimizations are enabled by default; there is no optimization toggle.

PERFORMANCE
The game has a fixed 30 FPS target. There is no frame-rate selection.
Legacy frame-rate preferences and vsync overrides are ignored.
Presentation uses vblank and sleeping deadlines, without busy waiting.
Main thread and helpers share cores 0-2; no single-core pinning.
Texture conversions use a shared work queue across the caller and two helpers.
CPU uses 500 MHz if accepted by the system, otherwise 444 MHz.
Idle reduction stops at 444 MHz; heavy frames restore the accepted ceiling.
No clock plugin is installed or modified by this VPK.
Normal play disables diagnostic file writes, the stall observer and profiling.

OPTIONAL LOGGING
Setup does not create a logging directory. Logging is OFF by default.
To collect a problem report, manually create this empty DIRECTORY after setup:
  ux0:data/pvz2/logging/
Then relaunch. It belongs beside libPVZ2.so, outside userdata/.
A file named logging is not enough.
Logs are written to ux0:data/pvz2/userdata/:
  loader.log, runtime.log, jni.log, stall.log (when applicable)
Each log is bounded to 2 MiB plus one previous copy.
Preserve the logs before relaunching. Include a matching psp2core dump if generated.
For a freeze, allow 30 seconds for the observer to capture it before closing.
Remove the logging directory and relaunch to disable diagnostics again.
Old logs remain untouched when logging is disabled.
On-screen setup/error messages still work.
